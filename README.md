# Hyprland Dotfiles (Fedora)

A clean, lightweight, and modern Hyprland configuration running on **Fedora Linux**.

## 🎨 Overview

This repository contains my personal dotfiles for a minimal Hyprland setup without unnecessary background daemons.

* **Compositor:** [Hyprland](https://hyprland.org/)
* **Status Bar:** Waybar
* **Application Launcher:** Rofi (Wayland)
* **Wallpaper Manager:** Swaybg
* **System Info:** Fastfetch

## 📁 Repository Structure

```text
.
├── fastfetch/    # Fastfetch configuration
├── hypr/         # Hyprland core configuration & keybindings
├── rofi/         # Rofi menu layouts & themes
